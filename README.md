# Trung tâm Tiếng Anh TTA
## Giới thiệu
**Trung tâm Tiếng Anh TTA** cung cấp các khóa học tiếng Anh phù hợp với *nhiều đối tượng học viên*. Dự án website giúp học viên tìm hiểu thông tin khóa học và đăng ký học thuận tiện hơn.
## Cấu trúc thư mục
| Thư mục | Nội dung |
| --- | --- |
| data | dữ liệu học viên và học phí |
| docs | tài liệu dự án |
| logs | nhật ký hoạt động |
| media | hình ảnh và video|
| archive | dữ liệu lưu trữ |
## Quy trình đăng kí học
1. Tìm hiểu các khóa học và mức học phí
2. Chọn khóa học phù hợp với nhu cầu
3. Cung cấp thồn tin và hoàn tất đăng ký tại trung tâm
